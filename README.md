# optical-radar-highway-project
 Autonomous Optical & Radar Highway Safety Sentinel
A Single problem solutions for alerting  the use of high beams which temporary blinds other drivers for highways and roads 

## Features
- *24 GHz FMCW Radar Front-End:* For optimum and accurate mesurement.
- *Differential Photometric Discrimination:* Different angle measurement for high vs. low beam identification.
- *Dynamic LED Matrix Driver Nudge:* Realtime display via P10 matrix.
- *Driver alert by Bluetooth connection on systems 

## System Architecture
[24 GHz mm Wave Radar ] -> [ESP32 Core] -> [P10 Matrix Display] -> [Bluetooth In-Cabin Alert System]
