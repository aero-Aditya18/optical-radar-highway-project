# optical-radar-highway-project
 Autonomous Optical & Radar Highway Safety Sentinel

An intelligent dual-modal roadside monitoring sentinel designed to combat high-beam glare blindness and night collision risks on single-lane roads.

## Features
- *24 GHz FMCW Radar Front-End:* Velocity tracking and range-gated distance calculation.
- *Differential Photometric Discrimination:* Dual-aperture optical angle measurement for high vs. low beam identification.
- *Dynamic LED Matrix Driver Nudge:* Real-time visual compliance feedback via P10 matrix.

## System Architecture
[24 GHz mm Wave Radar + Collimated Lux Array] -> [ESP32 Core] -> [P10 Matrix Display] -> [Bluetooth In-Cabin Alert System]
